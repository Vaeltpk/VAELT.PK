# VAELT — Easy Edit Website

## Files
- `index.html` — home page
- `style.css` — design
- `products.js` — **EDIT THIS FILE TO ADD/REMOVE PRODUCTS**
- `script.js` — website functions
- `product.html` — product detail page
- `product-style.css` — product detail design
- `product.js` — product detail functions
- `images/hero.jpg` — starting page image
- `images/product-1.jpg` etc. — add your product photos here

## Add a product
Open `products.js`, copy a product object, and change:
- code
- name
- brand
- size
- price
- condition
- image
- description

Put the matching photo in `images/`.

Example:
`image: "images/nike1.jpg"`
